# Cubs-2026-Almanac
A Chicago Cubs 2026 season tracker. Shows standings, the full 162-game schedule with viewing info, recent results, and upcoming games. Built to share with family and friends — no accounts, no installs, no cost.

**Status (2026-05-20):** the GitHub Pages site is unpublished and the scheduled GitHub Actions data refresh is paused. The workflow file is still in the repo and `workflow_dispatch:` is enabled, so a manual run from the Actions tab still works. To resume automation: restore the `schedule:` block in `.github/workflows/update.yml` and republish the Pages site.
